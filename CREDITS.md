# Assets and implementations

- Maps and scenery: the `village.tmx` map and tileset PNGs the user previously supplied in `assets.zip`. Kept as a fully editable Tiled project, with missing tile references repaired.
- Player animation: the supplied `player1` through `player12` sprite PNGs, following a polyline from `maps/village.tmx`.
- Contribution animation: the supplied `brio1` through `brio12` sprite PNGs; GitHub-style calendar with levels sourced from public GitHub data by workflow, not invented counts.
- Profile card: code-built SVG from the supplied profile editing project. Change the text and avatar in `editor.html`.
- No third-party font files are packaged; the card, Pathfinder, and Contribution designs use a code-defined 5×7 pixel alphabet.
